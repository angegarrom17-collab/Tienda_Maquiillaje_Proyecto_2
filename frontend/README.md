# Frontend — Tienda de Maquillaje (React + Vite + Bootstrap 5)

```bash
npm install
cp .env.example .env      # Windows: copy .env.example .env
npm run dev               # http://localhost:5173
```

Requiere el backend Django encendido en la URL configurada en `VITE_API_URL`.
Instrucciones completas, usuarios de prueba y arquitectura: ver el [README principal](../README.md).
